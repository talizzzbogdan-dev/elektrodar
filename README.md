# Сайт «Электродар»

Статический сайт для GitHub Pages: главная и четыре страницы услуг.

## Файлы
- `index.html`, `elektromontazh.html`, `voda-kanalizaciya.html`, `fundamenty.html`, `zhbi.html` — страницы
- `styles.css`, `script.js` — общие стили и скрипт
- `sitemap.xml`, `robots.txt`, `404.html` — для поисковиков
- `img/og.jpg` — превью ссылки в мессенджерах и соцсетях

## При подключении своего домена
1. Добавить файл `CNAME` с доменом (например `elektrodar.by`).
2. Заменить адрес `https://talizzzbogdan-dev.github.io/elektrodar/` на новый во всех `.html`, в `sitemap.xml` и `robots.txt`.
3. Подтвердить сайт в Яндекс Вебмастере и Google Search Console, отправить `sitemap.xml`.
